# Dg-pixel-art
Game Title: Dragon Ball Pixel Fighters

Main Goal:\
Choose a Dragon Ball character and fight against an AI opponent in a 2D pixel-art arena.

Player Controls:

- Left / Right arrows: Move.
- Up arrow (hold): Fly.
- Z: Transform.
- X: Physical attacks.
- C: Ki attacks.
- V: Character's special attack.

Gameplay:

- Select one of six characters: Goku, Goten, Gohan, Vegeta, Future Trunks, or Kid Trunks.
- Fight against an AI-controlled opponent.
- Fly, transform, punch, and launch energy attacks.
- Each character has unique abilities.

Scoring:

- Win a round to earn one point.
- Keep track of victories.

Win/Lose Rules:

- Win when the opponent's health reaches zero.
- Lose when your health reaches zero.

First Version:

- HTML, CSS, and JavaScript.
- One 2D pixel-art fighting arena.
- Character selection.
- Player versus AI.
- Health and Ki bars.
- Basic fighting, flying, and transformation mechanics.
- Compatible with GitHub Pages.
